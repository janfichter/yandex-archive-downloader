# 📥 Yandex Archive Downloader

Пользовательский скрипт (UserScript) для скачивания оригиналов архивных документов в высоком разрешении с сервиса [Яндекс.Архив](https://yandex.ru/archive/).

Скрипт автоматически перехватывает новый запрос `image-grant` (с токеном доступа), который Яндекс использует для защиты изображений, и позволяет сохранить файл одним кликом, обходя стандартные ограничения браузера.

---

## ⚡ Быстрая установка

1. Установите расширение **[Tampermonkey](https://www.tampermonkey.net/)** для вашего браузера.
2. Нажмите кнопку **«Установить»** в открывшемся окне Tampermonkey.

---

### Шаг 1: Установка менеджера скриптов
Если у вас еще не установлен Tampermonkey, добавьте его из официального магазина расширений:
* [Google Chrome / Яндекс.Браузер / Edge](https://chrome.google.com/webstore/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)
* [Mozilla Firefox](https://addons.mozilla.org/ru/firefox/addon/tampermonkey/)
* [Safari (macOS)](https://apps.apple.com/app/tampermonkey/id1482490089)

![Установка Tampermonkey](https://github.com/janfichter/yandex-archive-downloader/blob/77979ba34f20dffd61f843b79747babb0efcfa63/images/2026-11-02_18-37-50.png?raw=true)

### Шаг 2: Добавление скрипта
1. Кликните на иконку Tampermonkey в списке расширений и выберите "Создать новый скрипт".
2. Откройте в репозитории файл script.js и скопируйте все его содержимое.
3. Добавьте скопированный код в новый скрипт и нажмите Файл — Сохранить.

![Окно установки скрипта](https://github.com/janfichter/yandex-archive-downloader/blob/main/images/2026-11-02_18-55-23.png?raw=true)

### Шаг 3: Как пользоваться (Самое важное!)
1. Откройте нужную страницу с документом на [Яндекс.Архиве](https://yandex.ru/archive/).
2. В правом верхнем углу страницы вы увидите серую кнопку: **«⏳ Кликните по изображению...»**
3. **Кликните левой кнопкой мыши по самому архивному документу** на странице или немного приблизьте его колесиком мыши. Это заставит сайт запросить оригинал изображения.
4. Как только запрос будет перехвачен, кнопка мгновенно станет **зеленой** и изменит текст на **«🟢 СКАЧАТЬ ОРИГИНАЛ»**. В некоторых случаях кнопка сразу позволяет скачивание документа без ожидания.

   ![Кнопка стала зеленой и готова к скачиванию](https://github.com/janfichter/yandex-archive-downloader/blob/main/images/2026-11-02_18-59-28.png?raw=true)

5. Нажмите на эту зеленую кнопку. Браузер автоматически скачает файл в формате `.jpg` в вашу папку загрузок.

## ⚠️ Возможные проблемы и решения

| Проблема | Причина и решение |
| :--- | :--- |
| **Кнопка не появляется** | Убедитесь, что расширение Tampermonkey включено (иконка активна). Проверьте, что скрипт активен для домена `yandex.ru` (значок с цифрой "1" на иконке Tampermonkey). |
| **Кнопка есть, но при нажатии выдает ошибку** | 1. Отключите **AdBlock / uBlock Origin** для сайта `yandex.ru`. Они часто блокируют создание элементов со словом "скачать".<br>2. Возможно, Яндекс запросил капчу. Решите её на основной странице и попробуйте снова. |
| **Скачивается не тот файл (логотип вместо документа)** | Такое случалось в старых версиях. Убедитесь, что вы установили актуальную версию скрипта из этого репозитория. Перед скачиванием всегда дожидайтесь, пока кнопка станет **зеленой**. |

## 🛠 Для разработчиков

Скрипт написан на чистом JavaScript (Vanilla JS) и не требует внешних зависимостей. 
Основной механизм работы:
1. Перехватывает глобальный объект `window.fetch`.
2. Фильтрует запросы, содержащие эндпоинт `image-grant`.
3. Извлекает из JSON-ответа временные `url` и `token`.
4. Выполняет повторный запрос с заголовком `X-Archive-Image-Token` и флагом `credentials: 'include'`, чтобы использовать активную сессию пользователя.
5. Конвертирует ответ в `Blob` и инициирует скачивание через создание временного элемента `<a>`.

Любые Pull Request и улучшения приветствуются!
