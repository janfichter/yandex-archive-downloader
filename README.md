# 📥 Yandex Archive Downloader

Пользовательский скрипт (UserScript) для скачивания оригиналов архивных документов в высоком разрешении с сервиса [Яндекс.Архив](https://yandex.ru/archive/).

Скрипт автоматически перехватывает новый запрос `image-grant` (с токеном доступа), который Яндекс использует для защиты изображений, и позволяет сохранить файл одним кликом, обходя стандартные ограничения браузера.

---

## ⚡ Быстрая установка

1. Установите расширение **[Tampermonkey](https://www.tampermonkey.net/)** для вашего браузера.
2. Перейдите по [прямой ссылке на установку скрипта](https://raw.githubusercontent.com/janfichter/yandex-archive-downloader/main/yandex-archive-downloader.user.js) *(убедитесь, что имя файла в вашей репо совпадает)*.
3. Нажмите кнопку **«Установить»** в открывшемся окне Tampermonkey.

## ⚠️ Возможные проблемы и решения

| Проблема | Причина и решение |
| :--- | :--- |
| **Кнопка не появляется** | Убедитесь, что расширение Tampermonkey включено (иконка активна). Проверьте, что скрипт активен для домена `yandex.ru` (значок с цифрой "1" на иконке Tampermonkey). |
| **Кнопка есть, но при нажатии выдает ошибку** | 1. Отключите **AdBlock / uBlock Origin** для сайта `yandex.ru`. Они часто блокируют создание элементов со словом "скачать".<br>2. Возможно, Яндекс запросил капчу. Решите её на основной странице и попробуйте снова. |
| **Скачивается не тот файл (логотип вместо документа)** | Такое случалось в старых версиях. Убедитесь, что вы установили актуальную версию скрипта из этого репозитория. Перед скачиванием всегда дожидайтесь, пока кнопка станет **зеленой**. |

## 🛠 Для разработчиков

Скрипт написан на чистом JavaScript (Vanilla JS) и не требует внешних зависимостей. 
Основной механизм работы:
1. Перехватывает глобальный объект `window.fetch`.
2. Фильтрует запросы, содержащие эндпоинт `image-grant`.
3. Извлекает из JSON-ответа временные `url` и `token`.
4. Выполняет повторный запрос с заголовком `X-Archive-Image-Token` и флагом `credentials: 'include'`, чтобы использовать активную сессию пользователя.
5. Конвертирует ответ в `Blob` и инициирует скачивание через создание временного элемента `<a>`.

Любые Pull Request и улучшения приветствуются!
